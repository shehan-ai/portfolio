# Buwanaji — SC1153 Biotechnology Portfolio

Static academic portfolio. No build step.

- Preview locally: `python3 -m http.server` then open http://localhost:8000
- Deploy: push this folder to a GitHub Pages branch/root.

Structure:
- `index.html` — the whole site (inline CSS + JS)
- `hero.jpg` / `hero-small.jpg` — portrait
- `assignments/<n>/` — brief.pdf, marks.pdf, photo-*.jpg
- `absctract.md` / `conclution.md` — source text (already transcribed into index.html)
